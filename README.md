# Standalone 4G LTE Cellular Handset

An embedded mobile device built around a Raspberry Pi and Quectel EG25-G cellular modem, featuring serial AT-command handling, custom keypad interfacing, and Python automation.

## Project Architecture
- **SBC:** Raspberry Pi
- **Cellular Interface:** Quectel EG25-G 4G LTE Modem (Sixfab Base HAT)
- **Controls & Software:** Python 3, Serial Communication, Matrix Keypad Driver, Systemd Auto-start
